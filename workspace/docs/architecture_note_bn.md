# স্থাপত্যের নোট — ধীরে পড়ার জন্য

*(২৯ সেপ্টেম্বর ২০২৬। চ্যাটে যা আলোচনা হয়েছে তার সহজ সংস্করণ।
কোনো সিদ্ধান্ত এখনো নেওয়া হয়নি — এটা শুধু প্রস্তাব।)*

---

## এক লাইনে প্রশ্নটা কী ছিল

> ভবিষ্যতে সর্পিল, বর্গ, ত্রিভুজ — সব আকার লাগতে পারে। তাই এখনই কি একটা
> `3DObject` base class বানিয়ে তার নিচে সব সাজিয়ে রাখব?

আমার উত্তর: **না** — কিন্তু তোমার লক্ষ্যটা (নতুন আকার যেন সহজে ঢোকে)
সম্পূর্ণ সঠিক, আর সেটা অন্যভাবে পাওয়া যায়।

---

## ১. একটা সহজ তুলনা

একটা রান্নাঘরের কথা ভাবো।

**যেভাবে করতে চাইছিলে** — প্রতিটা খাবারের জন্য আলাদা যন্ত্র:

```
ভাতের যন্ত্র    →  ভাত রাঁধে
ডালের যন্ত্র    →  ডাল রাঁধে
মাংসের যন্ত্র   →  মাংস রাঁধে      ← কাল নতুন খাবার এলে? নতুন যন্ত্র।
```

**যেভাবে প্রস্তাব করছি** — একটা চুলা, অনেক উপকরণ:

```
উপকরণ কাটো  →  চুলায় দাও  →  পরিবেশন করো
```

নতুন খাবার এলে শুধু **নতুন উপকরণ** লাগে। চুলা বদলাতে হয় না।

আমাদের ক্ষেত্রে "চুলা" হলো **`MeshData`** — আর সেটা **ইতিমধ্যেই তৈরি**।

## ২. তিনটে ধাপ

```
   ধাপ ১              ধাপ ২                 ধাপ ৩
 আকার বানাও   →   বদলাও (ইচ্ছে হলে)   →   পর্দায় আনো

 uv_sphere()      .subdivide(2)          OBJMobject(mesh)
 extrude()        .decimate(20000)         .textured("x.jpg")
 "building.obj"   .displace("bump.jpg")     .wireframe()
```

**গুরুত্বপূর্ণ:** নতুন আকার যোগ করতে হলে **শুধু ধাপ ১** লিখতে হয়।
ধাপ ২ আর ৩ আপনাআপনি কাজ করে — কোথাও নিবন্ধন করতে হয় না, কোনো
base class-এ যোগ করতে হয় না।

উদাহরণ — নতুন একটা আকার:

```python
def torus_knot(p=2, q=3, thickness=0.05):
    return extrude(knot_path(p, q), circle_profile(thickness))
```

এই কয়েক লাইন লেখামাত্র `displace`, `decimate`, `textured`, `wireframe`,
`point_cloud`, `BuildMesh` — সব চলবে।

## ৩. কেন `3DObject` base লাগবে না

তিনটে কারণ।

**ক) manim-এ ইতিমধ্যে আছে।** `Surface` আর `Mobject` ঠিক এই কাজটাই করে —
"এটা একটা ত্রিমাত্রিক জিনিস" বলা। আরেকটা একই অর্থের স্তর বানালে শুধু
বাড়তি, নতুন কিছু নয়।

**খ) আকারগুলোও আছে।** ManimGL-এ আগে থেকেই: `Sphere  Torus  Cylinder
Cone  Cube  Prism  Square3D  Disk3D  Dodecahedron`, আর ২ডি-তে
`Circle  Square  Triangle  Polygon  Rectangle`…

**গ) সবচেয়ে জোরালো কারণ — এই প্রজেক্টেই প্রমাণ পেয়েছি।**
আমাদের দুটো আলাদা জিনিস আছে: ফাইল থেকে আসা মডেল, আর সূত্র থেকে আসা গ্রহ।
ওদের মিলটা কোথায় হলো?

- ❌ ক্লাসের বংশতালিকায় নয়
- ✅ **`MeshData`-তে** — অর্থাৎ ডেটায়

এটা আমি আগে অনুমান করিনি, **কাজ করতে করতে বেরিয়েছে**। আগেই base class
বানালে ভুল জায়গায় বানাতাম। আর ভুল কাঠামো পরে **মুছে ফেলা যোগ করার
চেয়ে অনেক কঠিন**।

## ৪. তাহলে ক্লাস কখন বানাব — একটাই নিয়ম

> ### জ্ঞান বহন করতে → ক্লাস
> ### নির্মাণ করতে → ফাংশন

| | কোনটা | কেন |
| --- | --- | --- |
| `Mars()` | **ক্লাস** ✅ | ব্যাসার্ধ ৩,৩৯৬,১৯০ মি, চ্যাপ্টা ০.০০৫৯, কোন DEM ফাইল — **এসব ব্যবহারকারীর মনে রাখার কথা নয়** |
| `helix()` | **ফাংশন** ✅ | শুধু জ্যামিতি বানায়, মনে রাখার মতো তথ্য নেই |
| `3DObject` | **কোনোটাই নয়** ❌ | জ্ঞানও বহন করে না, নির্মাণও করে না |

তাই তোমার দুটো ধারণার একটা ভালো, একটা নয়:

- `Planet → Earth, Moon` — **ভালো**, কারণ প্রতিটা নাম আসল তথ্য বহন করে
- `3DObject → 3DSpiralObject` — **নয়**, কারণ ওটা শুধু নির্মাণ

*(ছোট সংশোধন: base-টা `Planet` না হয়ে `Body` হোক — **চাঁদ গ্রহ নয়**,
গ্রহাণুও নয়।)*

## ৫. API দেখতে কেমন হবে

```python
# আকার — ফাংশন
mesh = extrude(helix_path(turns=4, pitch=0.35), circle_profile(0.07))
spring = OBJMobject(mesh, height=4, color="#C9A227").shade_smooth()

# বর্গাকার নল চাইলে — এক শব্দ বদল, আজ কিছু লিখতে হয়নি
mesh = extrude(helix_path(...), square_profile(0.07))

# গ্রহ — ক্লাস, সব জানে
from manimgl_myplugin.astro import Mars
self.add(Mars(radius=3))

# তালিকায় নেই এমন বস্তু
vesta = Body(radius=2, body_radius_m=262_700, dem="vesta.img")
```

আর তিনটেই — গ্রহ, সর্পিল, দালান — **নিচে একই কল নেয়**:

```python
for m in (mars, spring, house):
    m.shade_smooth();  m.wireframe();  m.point_cloud(4000)
    self.play(BuildMesh(m))
```

## ৬. পরের বার যে সিদ্ধান্তটা নিতে হবে

শুধু একটাই:

> **কোনটা দিয়ে শুরু করব — `shapes`, নাকি `astro` (মঙ্গল)?**

আমার মত: **`shapes` আগে**, কারণ `astro`-র গোলকটা (`uv_sphere`) ওখান
থেকেই আসবে। তারপর মঙ্গল বানানো সহজ হবে।

আর স্থাপত্যটা নিয়ে দ্বিমত থাকলে বা অন্যভাবে করতে চাইলে সেটাও বলো —
এখনো কিছু লেখা হয়নি, তাই বদলাতে কোনো খরচ নেই।
